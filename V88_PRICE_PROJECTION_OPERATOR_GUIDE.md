# Reading a V8.8 price projection

A target must never appear as a naked number.  Read it in this order:

1. **Bottleneck:** what resource, capacity, qualification, inventory, funding or access is scarce?
2. **Recipient:** which company, commodity grade, currency side or token actually receives the economic value?
3. **Activation:** what evidence says monetisation or recognition can begin inside the horizon?
4. **Low/base/high bridge:** which revenue, margin, scarcity rent, macro adjustment or token-value component creates each target?
5. **Probability:** how much weight is assigned to each scenario and how was that probability calibrated?
6. **Supply response:** when can competitors, new capacity, intervention or dilution close the gap?
7. **Invalidation:** which observable fact cancels the thesis before the target is reached?
8. **Proof status:** research-only unless the exact market receipt is valid.

Example interpretation: a base target of 100 is not a promise.  It means the frozen base assumptions generate 100 through the displayed value bridge.  The low target, probability-weighted expected target, error history and invalidation matter more than the base number alone.
