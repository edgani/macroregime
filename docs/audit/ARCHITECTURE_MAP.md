Derived from the AST import graph (`docs/audit/import_graph.json`, regenerated by
`tools/audit/import_graph.py`) and direct reads of the runtime files.

| Generation | Entry | State |

## 2. Production runtime surface (22 Python files, strict reachability from entry points)

Entry points: `app.py`, `run.py`, `warroom_data_worker_v101.py`, `shadow_runner_v101.py`.

```
app.py (Streamlit shell)
  -> dashboard.html  (8 tabs: mission, macro, alpha, us, idx, crypto, commodity, fx)
  -> run.build_desk(data_layer_v101.load_all(...))
  -> runtime_store (atomic snapshot JSON in runtime/ + static/ mirror)
  -> warroom/no_technical_policy.assert_registry_has_no_active_technical_components
  -> warroom_data_worker_v101.loop (daemon thread)

warroom_data_worker_v101.py
  -> current_context_v101.collect_all(fast=...)     # persistent collectors
  -> run.build_desk -> snapshot -> runtime_store
  -> shadow_runner_v101.record (only when WARROOM_AUTO_SHADOW=1)

Data plane:
  data_layer_v101.py   = data_layer.py (legacy bundled + FRED current-vintage)
                       + current_context_v101.py (persistent JSON collectors)
  current_context_v101.py collectors:
      quotes        Yahoo / Binance / CoinGecko -> runtime/current_context/quotes.json
      macro         FRED fredgraph.csv (14 series, CURRENT VINTAGE, not PIT)
      fundamentals  yfinance equity fundamentals
      crypto_network
      positioning   CFTC TFF (release-lagged)
      official_policy_rates  central-bank HTML scrape
  bundled_research_reader_v99.py  -> bundled research datasets (data/, evidence/)
  public_snapshot_reader_v98.py   -> public-source snapshots

Desk assembly:
  run.py               -> macro observations (flagged point_in_time_eligible=False),
                          mission_control, packets
  research_kernel.py   -> per-market causal sequence + projection methods + proof registry
  proof_registry_v99.py + global_market_promotion_gate_v99.py -> proof gating
  trading_readiness_v99.py + execution_reconciliation_v99.py  -> execution readiness audit

Decision packets:
  decision_packet_v99.py   -> per-ticker unified packet; market-specific causal sequences;
                              projection requests from runtime/v99_decisions|v98_decisions
  market_projection_engine.py -> scenario bridges: equity earnings/sales/fcf,
                              commodity scarcity, fx external-balance, crypto value-capture
  decision_packet_v101.py  -> thin adapter: base packets + action_engine_v101.enrich_packets
  action_engine_v101.py    -> research actions, shadow plans, alpha-center state
  carry_trade_engine_v101.py -> rate differentials + VIX/HY-OAS stress + CFTC TFF positioning
                              + beneficiary/unwind mapping (V101_CARRY_CAUSAL_MAP.json)

Prospective shadow (proto paper-trading):
  shadow_runner_v101.py -> shadow_execution_ledger_v95.py
                        -> runtime/v101_shadow/shadow_ledger.jsonl (append + verify)
```

## 3. UI inventory (dashboard.html)

Single-page dark dashboard, data injected as `window.DASHBOARD_DATA` (JSON snapshot).
Tabs (from `TABS=` in dashboard.html):

1. `mission` — Mission Control (permissions, carry state, promoted tickers, next actions)
2. `macro` — Macro & Risk
3. `alpha` — Alpha Center
4. `us` — US Stocks
5. `idx` — IHSG
6. `crypto` — Crypto
7. `commodity` — Commodities
8. `fx` — FX

`dashboard_live.html` (7.2 MB) is a generated standalone snapshot export, tracked in git (bloat).

## 4. Research/archival surface (everything else)

- 500 of 625 tracked `.py` files are NOT reachable from entry points + tests + src
  (import_graph.json). This includes the entire `gcfis/` 13-layer engine stack,
  `engines/` (24 engines incl. scrapers), `warroom/` (50+ modules, only
  `no_technical_policy` is in production), `alpha_foundry/`, and ~400 flat
  versioned scripts (`*_vNN.py`, v4..v100).
- 513 versioned report artifacts (`V*.json/md/txt`, `PACKAGE_MANIFEST*`).
- 85 `.bat` launchers, mostly per-version `CHECK_VNN.bat`.
- `hardening_tests/` — 12 script-style checks; NOT pytest-compatible
  (`test_options_gamma_v70.py` raises `SystemExit` at import, crashing pytest).
