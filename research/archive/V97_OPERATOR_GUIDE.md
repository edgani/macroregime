# V9.7 Operator Guide

## 1. Validate the package

Run `CHECK_V97.bat`.

Expected result: all V9.7 adversarial tests pass. This validates software behavior only.

## 2. Configure the environment

Copy `V97_TRADING.env.example` to `.env` and set a long private `WARROOM_HUMAN_APPROVAL_SECRET`. Never share it or commit it.

## 3. Refresh evidence and quotes

- Run `RUN_V97_PUBLIC_DATA.bat` for public/official research evidence.
- Run `RUN_V97_QUOTES.bat` for current execution-reference quotes.
- Run `RUN_V97_READINESS.bat` to generate the current machine-readable readiness report.

Quote failures remain visible and block orders. A cached old quote is never relabeled fresh.

## 4. Install a real exact-scope proof

A proof run must first be generated by the blind proof runner and installed in `component_registry_v97.json` with its exact relative path and SHA-256. Do not type a PASS boolean manually. No bound proof means no order.

## 5. Prepare a decision and account state

Copy:

- `V97_TRADE_DECISION_TEMPLATE.json`
- `V97_ACCOUNT_STATE_TEMPLATE.json`

Fill the exact instrument, venue, current account state, entry, stop, target, horizon, expected net return, lower-confidence return, causal chain, invalidation, contract metadata and proof binding.

## 6. Evaluate

```powershell
python trading_control_plane_v97.py evaluate --decision my_decision.json --account my_account.json --output my_evaluation.json
```

Only `AWAITING_HUMAN_APPROVAL` is a pass. `BLOCKED` and `NO_TRADE` must not be overridden.

## 7. Approve the exact evaluation

```powershell
python trading_control_plane_v97.py approve --evaluation my_evaluation.json --account my_account.json --approved-by "Edward" --output my_approval.json
```

Approval is HMAC-bound to the exact input hash and expires after 15 minutes.

## 8. Export the manual order ticket

```powershell
python trading_control_plane_v97.py export --decision my_decision.json --account my_account.json --evaluation my_evaluation.json --approval my_approval.json
```

V9.7 produces JSON and CSV in `runtime/v97_trading/orders/pending/`. It does not send the order. Re-check the broker's live quote, contract, lot, price band, borrow, margin and venue status before manually submitting.

## 9. Reconcile the actual fill

Use `V97_FILL_RECEIPT_TEMPLATE.json`, then run:

```powershell
python execution_reconciliation_v97.py reconcile --order runtime/v97_trading/orders/pending/<order>.json --fill my_fill.json
```

Only a live broker/exchange account export is admitted. Paper and synthetic fills are rejected.

## Emergency stop

```powershell
python trading_control_plane_v97.py kill --reason "reason" --actor "Edward"
```

Release requires the exact text `RELEASE V97 KILL SWITCH`.
