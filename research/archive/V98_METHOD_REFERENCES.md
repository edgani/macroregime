# V9.8 Method Map

V9.8 preserves the causal anti-overfit sequence:

`mapping → candidate registration → test → adjudication → final metric`

The UI architecture follows the decision path:

`world state → market opportunity → ticker → causal transmission → value capture → flow/positioning → projection → risk/execution → proof`

Price is allowed only as valuation denominator, current execution reference, outcome measurement,
liquidity/risk measurement and post-prediction invalidation. No chart-derived transformation can be
decision-active.
